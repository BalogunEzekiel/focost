# FOCOST Security Policy

FOCOST applies defence-in-depth: least privilege, RBAC, secure password hashing, CSRF protection, secure sessions, security headers, audit trails, request IDs, input validation, server-side payment verification, secret/environment separation, controlled database migrations and backup/recovery procedures.

Administrative functions are protected by explicit permissions. Sensitive authentication operations use one-time, hashed and expiring tokens and throttling.

Security vulnerabilities should be reported through the security contact published by FOCOST. Reports should exclude passwords, API keys and unnecessary personal information.
