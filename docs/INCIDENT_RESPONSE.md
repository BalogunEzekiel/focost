# FOCOST Security Incident Response

1. Detect and triage the event.
2. Create an incident record and preserve relevant evidence.
3. Contain the affected account, credential, endpoint, processor or service.
4. Rotate exposed credentials/secrets immediately.
5. Determine affected systems, users, data categories and jurisdictions.
6. Assess notification obligations under Nigerian law and any other applicable law (including GDPR where applicable).
7. Notify processors and affected parties through approved channels where required.
8. Eradicate the cause, restore from verified backups and monitor.
9. Record lessons learned and preventive controls.
10. Test the response periodically.

Do not place passwords, API keys or unnecessary personal data into incident tickets.
