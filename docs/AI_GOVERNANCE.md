# FOCOST AI Governance Baseline

- AI output is advisory/educational, not guaranteed financial, investment, tax or legal advice.
- Database-derived financial facts must come from authoritative application services rather than duplicated calculations.
- AI context must be minimised to the data required for the request.
- Provider/model names and relevant processing must be disclosed in the privacy documentation.
- Sensitive prompts must not be written to ordinary application logs.
- AI requests require subscription/entitlement checks and usage accounting.
- Provider failures must fail safely without inventing financial values.
- AI responses should distinguish computed facts from generated interpretation.
- Prompt-injection, data-exfiltration and unsafe-action testing should be part of security testing.
