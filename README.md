# Focost AI

An AI-powered financial coach designed to help individuals, businesses, churches, and NGOs make smarter financial decisions.

## Features

- AI Conversational Financial Coaching
- Income Tracking
- Expense Tracking
- Budget Management
- Financial Analytics
- Receipt OCR
- AI Insights
- Multi-currency Support
- REST API
- Enterprise Dashboard

## Tech Stack

- Python
- Flask
- SQLAlchemy
- Bootstrap 5
- JavaScript
- SQLite
- PostgreSQL
- OpenAI API
